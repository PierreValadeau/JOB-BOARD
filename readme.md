# JOB-BOARD – Portfolio PRE-MSC Epitech

Ce projet est une application de gestion d’offres d’emploi réalisée lors de mon PRE-MSC à Epitech. Elle permet la publication, la consultation et la gestion des annonces, des candidatures et des comptes utilisateurs (admin et candidats).

🗂️ Structure du projet
JOB-BOARD/
├── backend (PHP)
│ ├── api/ : Endpoints REST (jobs, companies, applications, users)
│ ├── controller/ : Logique métier
│ ├── model/ : Accès base de données
│ └── config/ : Configuration
├── frontend (HTML/CSS/JS)
│ ├── view/ : Pages principales
│ └── assets/ : Styles, scripts, images
└── sql/ : Script SQL de création de la base

🖥️ Technologies utilisées

- HTML5, CSS3, JavaScript
- PHP, MySQL

🚀 Fonctionnalités principales

- Publication et gestion d’offres d’emploi
- Candidature en ligne
- Authentification et gestion de profil
- Tableau de bord administrateur (CRUD)

📚 Objectif pédagogique
Mettre en pratique les compétences en développement web, gestion de base de données et sécurité dans le cadre du PRE-MSC Epitech.
