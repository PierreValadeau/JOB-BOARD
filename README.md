# Mini‑site d’annonces d’emploi

Ce projet a pour but de créer un **mini‑site d’annonces d’emploi** complet, avec base de données, affichage web, API et authentification.

## 🎯 Objectifs principaux

1. Créer une base de données avec les tables : `annonces`, `entreprises`, `utilisateurs`, `candidatures`.
2. Afficher les annonces sur une page web (HTML/CSS/JS).
3. Consulter les détails d’une annonce sans recharger la page (Fetch API).
4. Postuler à une offre via un formulaire.
5. Ajouter un système d’authentification et une page admin pour gérer les annonces.

## ⚙️ Stack suggérée

* **Backend** : PHP 
* **Base de données** : SQL / PHP MyAdmin
* **Frontend** : HTML / CSS / JavaScript
